# Smart Utility Toolkit

A hands-on Node.js core modules project demonstrating CLI applications, custom modularity, basic HTTP server routing, asynchronous file handling, and secure randomness generation without external packages.

## Technologies Used
* Node.js (Core Modules: `process`, `http`, `fs`, `crypto`)
* JavaScript (ES6)

---

## Utilities Included & How to Run

Performs basic arithmetic operations via command-line arguments.
